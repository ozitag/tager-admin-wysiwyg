# @tager/admin-wysiwyg

Визуальный редактор админки TAGER: [CKEditor 5](https://ckeditor.com/ckeditor-5/)
с набором плагинов и настройками проекта.

```ts
import TagerEditor from "@tager/admin-wysiwyg";
import "@tager/admin-wysiwyg/css";
```

Пакет отдаёт готовый к работе класс редактора — список плагинов, тулбар,
подписи заголовков и настройки таблиц уже заданы. Конфигурация доступна
отдельно как `defaultConfig`, если её нужно расширить на месте.

## Что внутри

`ckeditor5` подключён обычной зависимостью и **не вшит** в сборку: пакет
весит килобайты, а не мегабайты, и обновления CKEditor видны `npm audit` и
Dependabot.

До версии 2.0.0 всё было иначе. Пакет собирался из форка монорепозитория
CKEditor 5, замороженного на версии 21 (2020 год), и публиковался как
самодостаточный бандл на 7.9 МБ с вшитым внутрь редактором. Кастомизации
накладывались патчами на чужие исходники через `patch-package`. Ни один
инструмент не знал, какая версия CKEditor там лежит.

## Липкий тулбар

`StickyToolbarInScrollableContainer` прижимает тулбар к верху скроллящегося
контейнера, а не окна. Включается сам, если в документе есть элемент с
атрибутом `data-sticky-panel-limiter`; без него поведение штатное.

Нужен потому, что редактор в админке лежит внутри своей прокручиваемой
области, а штатный `StickyPanelView` считает смещение от вьюпорта — апстрим
это пока не чинит ([#18328](https://github.com/ckeditor/ckeditor5/issues/18328),
[#20265](https://github.com/ckeditor/ckeditor5/issues/20265)). Раньше то же
самое добивалось патчем на 174 строки, переписывавшим приватные методы
`StickyPanelView`; теперь это плагин снаружи, через публичное наблюдаемое
свойство `editor.ui.viewportOffset`.

## Лицензия

Самостоятельный хостинг под GPL: в конфиге стоит `licenseKey: "GPL"`, и в
углу редактора показывается логотип «Powered by CKEditor». Убирается только
коммерческой лицензией CKSource.

## Разработка

```bash
yarn install
yarn build       # vite build + декларации типов
yarn typecheck
```

Релиз выходит из ветки `master`: пуш туда запускает workflow публикации,
который пропускает версию, если она уже есть в npm.
